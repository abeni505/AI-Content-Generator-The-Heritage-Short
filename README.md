# The Gift We Couldn't Guess

An Amharic-language short film about our family's Christmas Eve surprise gift exchange. Two or three weeks before Christmas, each person draws another family member's name in secret and prepares a gift. On Christmas Eve, Father starts a chain of surprise gifts until everyone has received one.

The film is 84 seconds long, with nine storyboard shots, English subtitles, an original instrumental score, and an AI disclosure end card. It is exported in landscape (16:9) and portrait (9:16). The film is one example; `storyboard.json` is the input contract for the pipeline.

## Pipeline and implementation

`storyboard.json` is the shared contract. Its JSON Schema describes the required shot fields, and the validator checks the schema, unique shot IDs, and runtime before the Make targets run.

| Stage | Implementation | Inputs and outputs |
|---|---|---|
| Storyboard | JSON + `schema/storyboard.schema.json` | Shot duration, image and motion prompts, Amharic narration, English subtitle, rationale, and music cue |
| Narration | Gemini TTS, `pipeline/generate_narration.py` | Amharic lines become a WAV; content hash reuses an unchanged narration |
| Keyframes | Cloudflare Workers AI FLUX, `pipeline/generate_keyframes.py` | Prompts and optional family/style reference become still images |
| Moving shots | FFmpeg pan-and-zoom, `pipeline/generate_panzoom_clips.py` | Keyframes become 24 fps clips in both aspect ratios; this is the documented fallback for the unavailable Kaggle GPU session |
| Music | ACE-Step 1.5 XL through the ACE Music hosted interface | One selected instrumental score is stored at `outputs/audio/selected_original_score.mp3`; score generation is a manual step because no music API is wired into this pipeline |
| Assembly | FFmpeg, `pipeline/assemble_film.py` | Clips, narration, and score become subtitled H.264/AAC MP4s with side-chain ducking, loudness normalization, a fade, and the AI end card |

Keyframe cache entries hash the model, prompt, and reference image. Moving-shot cache entries hash their keyframe, duration, aspect ratio, and render settings. A changed shot invalidates its own keyframe and clips; unchanged shots are reused. Every provider call and local clip render is recorded in `runs.jsonl`.

## Run from a clean clone

The repository includes the current generated assets, so assembling the submitted film does not require API keys or a GPU:

```sh
git clone https://github.com/abeni505/AI-Content-Generator-The-Heritage-Short.git
cd AI-Content-Generator-The-Heritage-Short
make film
```

Requirements: Python 3, `make`, and FFmpeg with the `subtitles`, `drawtext`, `sidechaincompress`, and `loudnorm` filters. The command validates `storyboard.json` and writes both final exports under `outputs/final/original_score/`. It was run and checked locally; the Colab notebook provides a hosted Linux route, but has not been run end to end in Colab yet.

### Regenerate assets

To generate missing or changed narration and images, install the Python dependencies, copy `.env.example` to `.env`, and add your own Gemini and Cloudflare credentials. Never commit or share `.env`.

```sh
python3 -m pip install -r requirements.txt
cp .env.example .env
# Edit .env and set GEMINI_API_KEY, CLOUDFLARE_ACCOUNT_ID, and CLOUDFLARE_API_TOKEN.
make regenerate
```

Changed inputs can result in new provider calls and usage charges. Use `make regenerate FORCE=1` to regenerate all keyframes and clips, or regenerate one shot and reassemble with:

```sh
make shot SHOT=shot_03
```

For a different story, replace the storyboard with one that follows the schema, supply an appropriate reference sheet, and provide an instrumental score file with `MUSIC=path/to/score.mp3`. The score is not generated by `make regenerate`.

### Google Colab

Open `notebooks/Google_Colab_Run.ipynb` in Google Colab. The notebook clones this repository, installs FFmpeg and dependencies, runs `make film`, and offers an optional regeneration path using Colab Secrets. The current film assembles without GPU acceleration. Generating new narration or keyframes requires the user's own API credentials; Wan 2.2 is not part of this implementation.

## Validation and provider smoke test

```sh
python3 -m pip install -r requirements.txt
make validate
```

To check Gemini TTS and Cloudflare image access, set the credentials in `.env`, then run:

```sh
set -a
source .env
set +a
python3 pipeline/smoke_test.py
```

Smoke-test and generation latency, parameters, status, and output records are appended to `runs.jsonl`. Some providers do not return per-call billing data; estimated usage and limitations are in [`COSTS.md`](COSTS.md).
